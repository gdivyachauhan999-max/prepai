# Future Scope – PrepAI

This document outlines how PrepAI can evolve beyond Version 1.0.0.

---

# 3-Month Roadmap

## More Interview Domains

Add support for:

- Python
- C++
- JavaScript
- SQL
- System Design
- Operating Systems
- DBMS
- Computer Networks

---

## Difficulty Levels

Allow users to choose:

- Beginner
- Intermediate
- Advanced

before starting an interview.

---

## Improved Dashboard

Display:

- Weekly progress
- Monthly progress
- Average improvement
- Domain-wise analytics
- Score graphs

---

## Better UI

Enhance user experience with:

- Dark / Light Mode
- Better animations
- Custom illustrations
- Mobile-first improvements

---

# 6-Month Roadmap

## Voice Interviews

Allow users to answer using voice instead of typing.

---

## AI Resume Analysis

Upload a resume and receive:

- Resume score
- Missing skills
- Interview recommendations

---

## Personalized Learning

AI should recommend:

- Weak topics
- Practice questions
- Learning resources

based on interview performance.

---

## Leaderboard

Gamify the platform with:

- Weekly rankings
- Achievement badges
- Streak tracking

---

# 12-Month Roadmap

## Company-Specific Interviews

Generate interview experiences for:

- Google
- Amazon
- Microsoft
- Adobe
- Infosys
- TCS

---

## HR Interview Module

Prepare users for:

- HR questions
- Behavioral interviews
- Communication assessment

---

## Coding Playground

Integrate an online code editor for coding interviews.

---

## AI Career Coach

Provide:

- Career roadmap
- Skill-gap analysis
- Personalized learning plans

---

# Long-Term Vision

PrepAI aims to become a complete AI-powered interview preparation platform where students can:

- Practice technical interviews
- Practice HR interviews
- Improve communication
- Build resumes
- Track progress
- Receive personalized AI guidance

Version 1.0.0 establishes the core interview platform, while future releases will expand PrepAI into a comprehensive career preparation ecosystem.
