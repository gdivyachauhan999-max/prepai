# Challenge Retrospective – PrepAI

## Project Overview

PrepAI was developed as the final capstone project of the AB Talks 60-Day Claude AI Challenge. The objective was to design, build, deploy, and document a complete production-ready AI application following a structured 10-day sprint.

- Defined project scope and MVP.
- Selected React + Spring Boot + PostgreSQL.
- Designed application architecture.
- Planned authentication and interview workflow.
